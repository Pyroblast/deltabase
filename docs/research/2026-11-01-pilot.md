## 3. Educato：未确认 App，也可以完成可追溯研究

**用户与任务。** 公司面向备考学生；本轮重点研究其本地市场 UGC 负责人：从招募创作者到审核、发布、交付和支付的日常工作。这是从公开职责推导的用户任务，尚未通过访谈确认痛点强度。

**来源与直接观察。** 本地 YC 公司字段指向 `www.educato.com`；[YC 岗位页](https://www.ycombinator.com/companies/educato/jobs/wx7a1VE-ugc-campaign-manager-entry-level-marketing-role-experience-as-a-ugc-highly-desierable)可读，显示合同岗位、远程、`$10K - $45K`。[官网](https://www.educato.com/)进入英文页面，并有通往 [Educato Creators](https://creators.educato.com/) 的入口。来源页面未提供可核定的正文更新时间；观察日期均为 2026-11-01。

**公司自述。** 岗位要求按市场招募 TikTok/Instagram 创作者，协调内容反馈、交付与支付；本地语言能力是条件。创作者门户本轮显示葡萄牙语（巴西），说明按审核通过的视频支付、另有奖金，视频发布前由经理审查。门户宣称平均月收入 €800、最高 €4,000；这些是创作者收入宣传口径，不是单条视频报价、岗位薪资或公司总预算。页面语言也不证明投放仅覆盖巴西。

**身份边界。** 本地 `listings` 对名称和开发者的 Educato 检索未命中；本轮官网链接核验未建立可验证的 Apple ID 链路。因此状态是“未确认 App 关联”，不是“该公司没有 App”。手机界面图片及英文/葡文中的 app 一词都不足以确认 iOS 上架。

**推断与反证。** 多市场协调可能产生重复返工和版本混淆；但已有创作者门户及明确审核流程，说明公司可能已经解决了相当一部分工具问题。招聘也可能是需要本地执行人员，而非需要新软件。官网学生数字与创作者门户口径不同，未核定统计时间及分母，不据此计算用户增长。

**缺失证据。** 最近一个月实际活跃市场、每周交付数、返工轮数、经理耗时、现有系统覆盖、付款争议及实际付费意愿均未知。

**本轮决策与下一问。** 纳入机会实验优先样本，保留独立公司身份。最值得问：“最近一次视频被退回后，从改稿到获批再到结算，需要在哪些工具间核对，花了多久？”下一步在获得访谈授权并找到自愿参与者后，让 2 名类似团队负责人各回溯最近 5 条素材的脱敏操作记录；若流程已在现有门户内顺畅完成，则下调该假设。

## 6. 机会假设 H1：创作者返工与结算核对的轻量服务

**状态：待验证建议，未立项。** 先验证任务成本，暂不开发通用平台或新增 AI 功能。

| 要素 | 可执行定义 |
| --- | --- |
| 用户 | 假设为 2–10 人增长团队中管理至少 10 名活跃创作者、跨语言或跨市场交付的负责人；这些规模是招募筛选条件，不是上述公司的已知数据 |
| 触发任务 | 每周确认素材版本、处理返工、核对可发布内容与应付款项，形成下一轮 brief |
| 缺口假设 | 现有表格、消息和门户之间缺少一致的素材版本/批准记录，造成重复解释与结算核对成本；尚无访谈证明 |
| 支持线索 | Educato、BoldVoice 的岗位都明确包含审核和创作者运营；Educato 门户展示审核后发布与按条支付的连接 |
| 主要反证 | Educato 已有专门门户；BoldVoice 已有分析工具；困难可能在创意质量、本地语言和人手，不在系统；团队也可能不愿迁移数据或付费 |
| 提供物 | 人工辅助的单周素材交付清单：素材 ID、版本、修改原因、批准时间、发布链接、约定付款口径。先用参与者现有表格，不开发产品 |
| 可验证结果 | 负责人减少协调时间，遗漏/争议不增加，并愿意将下一周真实工作继续交给该流程 |

### 下一步实验协议

1. **问题访谈，授权启动后 7 天内。** 招募 5 名符合条件的负责人，至少覆盖 3 家互不关联团队，避免只验证这三个已选样本。每人 30 分钟，回看最近 5 条真实素材，记录工具切换、每条协调分钟数、返工原因、漏付/重付或版本误用；只收脱敏工作记录。不以“你会不会用”代替行为证据。
2. **进入小试点的门槛。** 至少 3/5 人能展示过去两周反复发生的问题，且各自每周协调耗时至少 2 小时；至少 2 人愿意提供下一周脱敏交付记录。若主要问题是创意质量或现有门户已覆盖，则停止此工具方向。
3. **两周人工试点。** 对 2 家愿意参与的团队，第一周观察现有流程，第二周使用统一清单，每队每周至少 10 条素材。逐条计时，按相近素材类型比较中位协调耗时；单独报告素材数量、复杂度和返工轮数差异，不宣称随机实验因果结果。
4. **预先约定成功/失败。** 两队各减少至少 30% 中位协调时间，版本误用/漏付不增加；向两队提出下一周期每月 US$100 的真实服务报价（实验价格，不是市场估值），至少一家实际付费续用才进入进一步验证。仅口头喜欢不计成功；无人付费、节省主要来自研究人员额外劳动而不可持续，或需大规模替换现有门户时，停止或收窄服务范围。
5. **当前执行状态。** 已完成案头筛选与反证核查；未联系公司、未招募、未发送消息、未试点、无付费结果。研究负责人维护记录；外联和实际服务需另有明确任务授权，本轮不代用户发送。

这些门槛是试点决策规则，不是从三案例得出的统计结论。即使试点成功，也只支持继续研究该任务，不证明完整创业机会或 PMF。

本地数据复核可在只读连接中执行以下查询；不调用应用启动入口，避免隐式迁移或采集：

```sql
SELECT id, name, website FROM growth_companies
WHERE id IN ('yc:29605', 'yc:24065', 'yc:23832');
SELECT id, first_seen, last_checked, payload FROM growth_leads
WHERE id IN ('yc:107033', 'yc:86698', 'yc:49264');
SELECT lead_id, observed_at, event FROM growth_versions
WHERE lead_id IN ('yc:107033', 'yc:86698', 'yc:49264');
SELECT app_id, market, name, developer FROM listings
WHERE app_id IN ('1567841142', '1485756576');
SELECT s.source_id, s.observed_at, s.source_updated_at, r.rank
FROM ranks r JOIN snapshots s ON s.id = r.snapshot_id
WHERE r.app_id = '1567841142' ORDER BY s.observed_at;
```

交接优先级：先由总控验收三个身份状态的研究路径；再决定是否启动 H1 的问题访谈。没有足够证据支持扩大为融资开发、收入估算、自动配对或 AI 分析。
