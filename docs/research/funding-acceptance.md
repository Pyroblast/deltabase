# 融资手动 MVP：真实验收数据包

准备日期：2026-11-01（北京时间）。状态：**资料已核验、数据包已准备；产品/API/浏览器验收未执行。**

配套文件：[funding-acceptance.json](funding-acceptance.json)。依据：[融资 MVP 方案](../design/funding-mvp.md) F01–F12、[既有研究试点](2026-11-01-pilot.md)。本轮仅写入这两个研究文件，不改接口契约、源码、数据库或 Git，不运行服务/E2E，不采购或外联。

## 使用方式与计数

JSON 顶层是中立研究格式，**不能原样 POST 给 API**。交付前已只读核对刚出现的 `shared/funding.ts`、`docs/design/funding-api.md`，增加 `apiDrafts`：其中每项 `data` 按当前 `FundingDraft` 形状准备，可供执行者添加请求幂等键后在隔离环境验证。本轮没有调用 API；契约仍在实现中，最终以运行时校验为准。

在隔离数据库中依次录入三个 `records`。公司 ID 仅是既有研究定位提示；空测试库可以创建对应身份，副本则人工核对后复用。不得只按名称自动选择公司，也不得把 fixture ID 当生产主键。

基线预期为 **2 条融资公告事件 + 1 条待核验线索 + 4 份主证据**。其中 Agave 一轮包含公司、投资方两份公告；另有文章目录与 YC 公司页共两张辅助页，分别支撑日期和身份。若实现把辅助页也保存为证据，证据总数可增加，融资事件数仍为 2。这里的“已核对”仅指读过来源陈述，不代表独立确认到账。

`acceptanceScenarios` 中每项从干净基线或独立测试分支开始。A06 的历史种子轮与 A07–A10 的合成材料不计入基线的两轮真实公告。合成公司、金额、失败和测试时钟均已标记，不得写回真实案例或个人数据库。

## 三组真实样本与字段边界

| 样本 | 可采用的披露 | 仍须未知或单独标注 |
| --- | --- | --- |
| BoldVoice | 2026-01-28 公告；A 轮；本轮 `$21 million`；Matrix 领投；本轮参投名单见 JSON | 发生/交割日、估值、资金到账未知；币种 ISO 未显式披露；稿件是公司发布 |
| Agave | 2026-07-07 公告；A 轮；公司称本轮 `$15M`、累计 `over $20M`；Accel 领投、YC 参投 | 累计是严格下界，不是精确 20M；不与本轮相加；投资方文章不支持本轮金额或 YC 本轮参投 |
| Educato | 官网确认 YC 背景，可保存待核验线索 | 不填轮次、金额、融资公告日、交割日；不套用 YC 通用投资条款；未确认 App 不等于没有 App |

来源均于 2026-11-01 用网页阅读工具重新核验，可能使用缓存；每份来源的发布时间、定位、支持字段和不支持字段保存在 JSON。未获取来源更新时间时为 null。

**BoldVoice 的发布角色。** [PR Newswire 稿件](https://www.prnewswire.com/news-releases/boldvoice-raises-21m-series-a-to-give-a-billion-non-native-english-speakers-their-own-ai-voice-coach-302671777.html)标明发布者为 BoldVoice；平台不是独立记者。文末背景名单中的 Liquid 2 不应混进本轮参投名单；ARR 也不是融资额。原始发布时间有 ET，按美国东部冬令时转换为 `2026-01-28T14:30:00Z`，并保留原文和转换依据。发生日仍为空。

**Agave 的字段级证据。** [公司公告](https://useagave.com/blog/announcing-agaves-15m-series-a)支持金额；[Accel 公告](https://www.accel.com/news/leading-agave-s-series-a-ai-infrastructure-for-the-construction-industry)支持轮次、领投、公告日及公司域名。两方均为交易相关方，不是两份独立审计。公司详情的日期来自[官网文章列表对应卡片](https://useagave.com/blog)，不能声称详情正文直接显示日期。事件公告日可直接采用 Accel 的日级日期，不补 UTC 零点。

**Agave 身份。** Accel 正文指向 `useagave.com`，公司公告的招聘入口指向 [YC Agave](https://www.ycombinator.com/companies/agave/jobs)，YC 页面回指 `www.useagave.com`。这是选择 `yc:25273` 的依据，而非“名字一样”。本包不确认或创建 App 关联。

**Educato 的缺口。** [官方 Press 页面](https://www.educato.com/press)只支持背景线索；YC 批次、页脚年份和 App Store 评分宣传均不能替代融资日期、金额或 Apple ID。页面未披露不等于公司未融资。

美元符号的处理采用保守验收值：保留原文和数值量级，`currency: null`。若操作者基于美国主体及语境选择 USD，应记录“人工解释”与依据，不能把它伪装成来源明确写出的 ISO 代码；测试中另有显式 USD 合成值，验证正常币种路径。

## 当前契约的适配要点

| 研究数据 | 当前 API 对应 | 保真要求 |
| --- | --- | --- |
| `funding_event` / `unverified_lead` | `recordKind: event / lead` | Educato 使用 `verification: unverified`，表示具体融资事件未核定；来源背景已读不提升事件确定性 |
| 多个 `amounts` | 单个 `amount` | Agave 主字段选本轮；累计严格下界留在 notes 和公司证据 summary，不伪造第二轮 |
| 数值量级已知、币种未明 | `currency: null, value: null` | 契约要求规范化数值有币种；研究层的 21000000/15000000 不直接提交。原文金额照常保存 |
| `lower_bound_exclusive` | `kind: lower_bound` | API 没有独立比较符字段；必须保留 over 原文及“严格大于”摘要，不能变为大于等于 |
| 公司稿/分发平台 | `role: company`，publisher 为公司 | PR Newswire 仅在摘要说明分发身份，不改为 media |
| 投资方相关方陈述 | `role: investor` | 标为 source_checked 不表示独立审计；Accel 的 supports 不含 amount |
| 字段级来源 | evidence.supports + investors.evidenceKeys | 本轮金额只指公司稿；Accel 领投指两来源，YC 参投只指公司稿；细粒度差异仍保留摘要 |
| 精确发布时间/日级公告日 | 证据 `instant` 或 `day`；事件 `published: day` | BoldVoice 证据保留 ET 原文及 UTC 时刻；Agave 日级不补时区；发生日全空 |

若只追加 Accel 证据后未同步投资方的 `evidenceKeys`，详情可能有两份文档但领投仍只指公司来源；执行 A02 应进一步完整编辑关联字段，检查版本与来源关系都可追溯。预期最终数据为 `apiDrafts` 中 Agave 的形状。公司文章日期由目录辅助核对，相关 URL 和定位已写入该证据摘要。

## 产品验收顺序与反例

| 顺序 / JSON 场景 | 操作与判定重点 | 失败反例 |
| --- | --- | --- |
| A01（F01/F11） | 今天录入 BoldVoice 旧公告，分别显示收录日、公告日、未知发生日 | 一月公告显示为今天完成融资；首次收录时间回填一月 |
| A02（F02） | Agave 公司先建轮次，投资方追加；逐项打开金额/领投/日期依据 | 两条 URL 变成两轮；金额指向未披露金额的 Accel 文；累计与本轮相加 |
| A03（F04） | Educato 无金额无日期也能保存线索 | 为满足必填项填 0 或默认种子轮；把线索计为确认轮次 |
| A04（F03/F07） | 相同幂等键重试，再显式无变化核验 | 重试增加观察；核验制造新事件/新内容版本；首次收录变化 |
| A05（F03） | 追踪参数复用、业务参数保留，原 URL 可追溯 | 所有查询参数被删；不同业务文档被误并 |
| A06（F03/F05） | Accel 同文档还提及此前种子轮，可另挂历史待核验记录 | URL 被当成事件唯一键；A 轮金额/公告日复制到种子轮；旧文日期当交割日 |
| A07（F05/F10） | 两个合成同名、不同官网公司；新增纯融资公司 | 自动合并到真实 Agave；增长公司统计虚增；生成假招聘 |
| A08/A09（F06） | 本轮/累计/估值、约数/区间/下界、未知币种、混合债务分别检查 | 将 5M+累计 8M+估值 30M 合成融资额；数千万变精确数；未知变 0 |
| A10（F05/F07） | A→B→A 留三版本；同值保存；来源冲突；轮次追加 | 回到旧值丢历史；冲突默默覆盖；只凭同轮名合并追加融资 |
| A11（F08） | 人工记录访问失败；隔离测试模拟事务失败 | 失败清空有效证据；认为融资撤回；半条记录或虚假保存成功 |
| A12（F09/F10/F12） | 无 App 公司保存/重开/重启；解除已有 App 关联 | 融资依赖 App 或岗位才能存在；解除 App 顺带删融资；覆盖旧笔记/榜单 |

补充观察：本轮 Accel URL 首次直接打开失败，随后从官方公司页链接成功读取同一 URL。这提供了真实的“工具访问失败不等于撤稿”例子；自动化失败测试仍应使用受控模拟，不依赖公网临时故障。

## 执行记录要求

执行方分别记录测试时钟、隔离数据库、操作前后事件/线索/证据/版本/观察数量、实际结果和失败原因。确认幂等请求前后数量不变；显式无变化核验仅增加观察；追加不同来源保留字段支持关系。比较公司计数时区分通用身份总数与有增长线索的公司数。

重启与失败测试由总控协调独占测试端口/目录。本包未操作 Chrome，也未占用 3100。两条真实公告足以验收手动闭环，不能宣称融资来源全量覆盖；当前未提供中国公告、SAFE 条款或真实金额冲突样本，这些只覆盖合成规则路径。

本轮验证只包括一手页面核对、JSON 可解析性、内部引用和预期数据结构检查。最终构建、API、浏览器和人工产品验收由实施/总控另行报告，不沿用数据包的“准备完成”作为通过证据。
