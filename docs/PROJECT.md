# Deltabase 项目范围与路线图

更新：2026-11-02（北京时间）。负责人：项目总控与架构。

## 定位

本地个人产品与创业机会研究工作台：发现变化 → 核对证据 → 持续观察 → 形成机会假设 → 体验、访谈或实验验证。核心资产是关联后的产品与公司、可追溯证据历史和研究判断。

三类信源为中美 App Store、增长招聘与创作者推广、融资与公司动态。研究不要求三类信源同时命中；没有 App 或没有公开融资的公司也能独立存在。

## 已确定范围

- 本地自用、React/TypeScript + Fastify + SQLite/Drizzle，暂不加入云同步和账号系统。
- App Store 覆盖中美非游戏类别，免费/畅销交叉观察，付费榜独立观察。
- 信源二优先 YC Jobs 公开 Marketing 样本；SideShift/Wellfound 手动录入。
- 信源三手动 MVP 已验收：融资公告录入、公司关联、同轮多来源与保守去重；版本、核验记录与独立时间口径，暂不自动抓取。
- 前端采用石墨白、紧凑列表和证据侧栏。
- 更新采用启动时过期检查与手动刷新；常驻定时采集仍属后续。
- 用户已授权建立长期对话协作、执行收口与验收，并连接私人 GitHub 仓库。

## 优先级与验收

1. M1 联合收口：石墨白前端与增长 MVP；原有收藏/笔记不回归；YC 真数据可追溯；手动线索可编辑并持久化；重复采集去重；公司/App 关联可确认与撤销。
2. M2 工程基线：构建、规则/API、浏览器流程通过；私有 GitHub 仓库仅包含源码、测试与文档，建立可回退提交。
3. M3 研究闭环：至少 3 个真实案例（含无 App 公司），明确事实/推断和缺失证据；至少 1 条具有下一步验证动作的机会假设。不能为了验收编造关联或结论。
4. M4 融资MVP：2026-11-01 已完成实施与联合验收，手动录入、公司关联、去重、证据历史和持久化通过；本地服务已升级。F01–F12 证据见 `docs/qa/funding-mvp.md`。

AI 提取与分析、赛道地图、自动定时、外部收入估算和跨设备同步均为后续候选，不能挤占当前收口。

2026-11-01补充：融资竞品深化调研已完成，包含Harmonic发现/提醒流程及三家平台同样本比较。下一阶段建议先验证授权数据，再做候选收件箱、人工核验和观察名单；供应商采购与自动接入尚未确定。[方案与依据](design/funding-discovery-next.md)
